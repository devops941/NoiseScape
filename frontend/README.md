# NoiseGuard — Frontend Application

A single-page React dashboard built with Vite, Tailwind CSS, Leaflet for geospatial noise mapping, and Chart.js for ambient acoustic trend analysis.

## Setup & Running

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
copy .env.example .env   # On Windows
# cp .env.example .env   # On Linux/macOS

# 3. Start development server
npm run dev
```

The application runs on `http://localhost:5173`.
